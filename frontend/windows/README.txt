MYKOKNOKS WINDOWS — ONE-CLICK INSTALL

1. Extract the entire ZIP archive to a folder.
2. Double-click INSTALL-MYKOKNOKS.cmd.
3. The script verifies the installer SHA-256 against SHA256SUMS.txt.
4. It tests the MykoKnoks Ultra API, installs the app silently, and starts MykoKnoks.

If Microsoft SmartScreen appears, note that community/test builds may not yet carry a commercial Authenticode certificate. Only continue if you trust the build source and the SHA-256 verification succeeds.
